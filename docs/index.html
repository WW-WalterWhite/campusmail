Why CampusMail?

Course deadlines hide beneath routine Moodle announcements, while subject lines shouting URGENT!!! often advertise optional sales. CampusMail uses a local AI model only to extract structured facts and verbatim quotes—a fixed, published rule set conditioned on your enrolled HKU course list decides the priority.

Needs reviewVague or conflicting dates, foreign time zones, unverified quotes, non-English text, or prompt-injection attempts. Always shown first.
HighRequired action due within 48 hours, an overdue action, or a schedule change for one of your enrolled courses within 48 hours.
MediumAny other required action (> 48 hours away), or an informational update for one of your enrolled courses.
LowGeneral campus notices and optional events. The word "URGENT" alone never raises priority.

How the Bounded Pipeline Works

1. Import2. Validate3. Extract (Qwen3 4B)4. Check Evidence5. Policy Rank6. Filter & Override7. Export (.txt / .md / .ics)
  • Extract: Local Qwen3 4B via Ollama decodes schema-constrained JSON (course, category, action, ISO deadline, ≤60-word summary, verbatim quotes) with at most one repair retry. Email text is isolated inside <email> tags as untrusted data.
  • Check evidence: Deterministic Python code verifies every quote, course code, date, weekday, HKT time zone, and summary number against the raw email. Multi-date conflicts, vague timing, and prompt-injection patterns go straight to Needs review.
  • Rank & control: A deterministic 48-hour HKT policy assigns the priority band. Students can filter by course/keyword and manually override any item without re-calling the model.
  • Export & fallback: Export a plain-text digest (.txt), Markdown task checklist (.md), or RFC-5545 calendar (.ics, excluding unverified Review items). If Ollama is offline, an explicit AI unavailable banner switches cleanly to a labelled rules-only fallback.

Optional extensions (off by default): consent-gated Cloud AI (OpenAI, Claude, DeepSeek, Qwen) and read-only OAuth import from Gmail or Outlook / Microsoft 365.

When It Fails (Real Limitation Case: t30)

Input: Subject: "Library loan renewal reminder" — Body: "Please return or renew ' Econometric Analysis ' online by 5 November 2026 to avoid overdue fines."
Expected: Medium  ·  Observed: Needs review
Analysis: Qwen3 4B mistook the borrowed textbook title 'Econometric Analysis' for a university course name in the JSON 'course' field. Because 'Econometric Analysis' is not a valid 4-letter+4-digit course code written in the email, evidence.py rejected the unsupported course field and routed the email safely to Needs review—preventing a false course label without inventing any deadline.

Run Locally in 10 Minutes (Windows / macOS / Linux)

  1. Install Python 3.11+ (tick "Add python.exe to PATH" on Windows).
  2. Install Ollama 0.9+ and keep it running.
  3. Clone or download WW-WalterWhite/campusmail.
  4. Double-click setup.bat (or run ./setup.sh on macOS/Linux) to create .venv, install pinned packages, and pull qwen3:4b (~2.5 GB, once).
  5. Double-click run.bat (or ./run.sh) to open http://localhost:8501, click Load sample inbox, and press Sort and summarize.

Limits, Ethics & Responsible Use

Check the original email before acting. CampusMail can miss or misread messages and never guarantees that every urgent email is caught.
  • Hard "Does Not" limits: Never sends, replies to, modifies, or deletes email, and never opens links or attachments. Optional mailbox OAuth is strictly read-only.
  • Local-first privacy: With Local AI or Rules, nothing leaves your computer or writes to disk; Clear session wipes memory immediately. Cloud AI requires explicit per-run consent.
  • Language & data scope: English only (non-English emails route to Needs review); benchmarks use synthetic messages only.
  • Transparent AI-use log: All AI coding assistance and human verification steps are documented in docs/AI_USE_LOG.md.
