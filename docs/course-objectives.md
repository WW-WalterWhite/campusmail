# AILT9019 Course Objectives

**AILT9019 · AI Literacy for Computing and Data Science (AI Literacy II)**
2026–27 Semester 1 · 3 credits · 100% coursework · Distinction / Pass / Fail

Source: `00_Course_Overview.pdf`, `AILT9019_Midterm_Check_Requirements.pdf`, `AILT9019_Midterm_Rubric.pdf`.

## Core objectives

In teams of 3–4, students build a focused, working AI application for one domain they choose (campus life, study & learning, health & fitness, personal finance, arts & culture, and more), using AI coding tools on their own computers. The project runs through the full pipeline: **proposal → development → presentation**.

The course builds three capabilities:

1. **Identify** suitable AI development tools.
2. **Apply** them to a real-world problem.
3. **Critically assess** the ethical and societal impact of AI systems.

## Final deliverables

- **Project webpage**: the problem, what the system does, how it works, how to run it locally, what a successful run looks like; a real demonstration and a link to the GitHub repository.
- **3-minute presentation plus demo**: problem, approach, one successful run, one limitation or failure case, and what was learned.
- **Report** of at most 5 pages (appendix unrestricted), including an **Ethics & AI-use disclosure**.
- Participation in the W13 Gallery peer review, People's Choice vote and closing.

## Mid-term check (26 Oct 2026, 5%, 20 points)

One team ZIP (max 100 MB) on Moodle containing:

1. **1-minute recording (mp4)**: one real input, the system processing it, and the output; narrated or captioned; no slides in place of a running workflow; no personal data or API keys.
2. **`repository_link.txt`**: repo URL; staff need access, and the README must explain setup, how to run the core path, and how to check the result.
3. **One-page status sheet**: what works now, test evidence and limitations, blockers with owners, three dated milestones for the next two weeks, each member's contribution, and the scope decision.

| Criterion | Points |
|---|---|
| Core workflow (real input → processing → output, reproducible) | 0–6 |
| Repository and reproduction (README, example input, expected output) | 0–4 |
| Testing and limitations (input, expected vs actual, evidence, known limitation) | 0–3 |
| Blockers and plan (owners, three dated milestones, explicit keep/cut scope) | 0–4 |
| Member contribution (per student, 0 or 3) | 0 / 3 |

## Academic integrity

Honest disclosure of AI use is required. Do not misreport contributions, fake demonstrations, submit work that is not the team's, or present another person's work as your own.
